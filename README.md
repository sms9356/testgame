# 폐교 — 다시, 여기서

레퍼런스 시트(폐교 배치도·정문·교실·소품)를 바탕으로 만든 1인칭 3D 학교 공포 게임. 브라우저에서 바로 실행됩니다 (Three.js, 외부 에셋 없음 — 텍스처·사운드 모두 코드로 생성).

## 실행
```
python3 -m http.server 8000   # 또는 아무 정적 서버
# 브라우저에서 http://localhost:8000 접속 후 "입장하기"
```
(ES 모듈을 쓰므로 `file://` 로는 열리지 않습니다.)

## 목표
정문이 등 뒤에서 잠긴다. 학교 곳곳(교무실·도서실·과학실·음악실)에 흩어진 **열쇠 조각 4개**를 모아 정문을 열고 탈출하라. 첫 조각을 줍는 순간 그것이 깨어나 학교를 배회한다.

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 마우스 | 이동 / 시선 |
| Shift | 달리기 (체력 소모, **소리가 나서 들킴**) |
| F | 손전등 (건전지 소모, 건전지 줍기 가능) |
| E | 줍기 · 쪽지 읽기 · 사물함에 숨기/나오기 · 계단 오르기 · 정문 열기 |
| Q | 계단 내려가기 |

## 구성 (레퍼런스 반영)
- 3층 본관(1F 보건실·상담실·교무실·1-1~1-3·도서실 / 2F 교실·컴퓨터실·과학실 / 3F 교실·미술실·음악실), 중앙 계단, 각 층 화장실, 복도 사물함
- 폐교 정문(기둥 "폐교" 현판, 녹슨 철문, 출입금지 경고판), 운동장, 체육관·급식실 외관, 담장, 숲
- 유령 AI: 순찰 → 소리/시야 감지 → 추격 → 수색. 사물함에 숨어 따돌릴 수 있지만 숨는 걸 들키면 끝.

## 파일
