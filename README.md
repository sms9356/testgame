# 폐교 — 잊혀진 시간

10년 전 그날 밤, 지하 펌프실에 갇힌 채 잊힌 한 학생. 그 괴담을 찍으러 들어갔다 사라진 친구 민아를 찾아 폐교에 들어간 주인공이, 빛과 소리에 민감한 존재를 피해 그날의 기록을 모으고 **잊힌 이름을 마지막 하교 방송으로 돌려보내는** 1인칭/3인칭 3D 공포 어드벤처입니다. 브라우저에서 바로 실행됩니다 (Three.js).

- **온라인 플레이:** https://sms9356.github.io/testgame/ (테스트 모드: https://sms9356.github.io/testgame/?test)
- **PC 전용** — 키보드 + 마우스, Chrome · Edge 권장, 헤드폰 권장. 모바일 조작은 지원하지 않습니다.
- 개발 기록은 [CHANGELOG.md](CHANGELOG.md) 에 있습니다.

## 실행
```
python3 -m http.server 8000     # 또는 npm start
→ http://localhost:8000 → 새 게임 → 주인공 선택
```
ES 모듈을 쓰므로 `file://` 로는 열리지 않습니다. `main` 에 머지되면 워크플로가 `gh-pages` 를 갱신해 자동 배포됩니다.

## 게임 구성
| 요소 | 내용 |
|---|---|
| 주인공 | **지훈**(18, 관찰형: 체력 +25% · 단서가 반짝임) / **서연**(17, 방송부: 배터리 −25% · 그것의 방향 감지). 대사 · 목소리 · 표정 · 시작 소지품 · 전용 기록이 다름 |
| 목표 | 정문 열쇠 조각 **5개**(교무실 금고 · 도서실 · 과학실 · 체육관 · 수영장) → 소지품에서 조합 → 정문 · 서문 · 지하 비상 통로로 탈출 |
| 퍼즐 | 금고(그날의 날짜), 자물쇠 따기(머리핀), 다이얼 자물쇠 2종, 배선 퍼즐(퓨즈), 피아노, 사진 맞추기, 갈고리 낚기(조합), **마지막 방송 — 녹음 순서 복원** |
| 진실 | 쪽지 · 녹음 · 사진 · 캠코더 · 서로 모순되는 증언을 모으면 휴대폰의 **사건 연표**가 채워진다 |
| 엔딩 | **TRUE** 하교 방송 + 민아 구출 · **NORMAL** 혼자 탈출 · **BAD** 쓰러짐(구조 요청 기록 해금) — 정문에서 **마지막 선택 A 진실 공개 / B 함께 떠난다 / C 은폐** 에 따라 후일담이 달라짐 |
| 수집 | 문서 · 사진 · 녹음 · **교실의 기억 22개**(3개마다 보급품) · 기억 조각 |
| 생존 | HP · 스태미나 · 배터리 · 공포, 달리기 소음, **앉기 · 점프**, 사물함 은신 + 숨 참기, 캔 던져 유인, 손전등으로 퇴치, 안전 구역(보건실 · 별관 진로상담실) |
| 지역 | 본관 1~3F(복도 양쪽 방 · 층당 18칸) · 옥상 · 지하 B1(A01~A10) · 체육관 · 수영장(5구역) · 급식실 · 별관 1~3F |

## 저장
- 자동 저장(열쇠 · 장치 · 안전 구역 진입 등) + 수동 저장. 저장 시각 · 위치가 타이틀과 일시정지 화면에 표시됩니다.
- `saveSystem.js`: 스키마 버전, **고유 ID 기반**(아이템 · 장치 · 문 · 이벤트 · 팁), 캐릭터 복원, **백업 슬롯**(손상 시 자동 복구), 이전 버전(v4) 세이브 자동 변환, 진행 상태 보정(필수 아이템 영구 소실 방지).
- 테스트 모드(`?test`)는 별도 저장 키를 써서 실제 세이브를 바꾸지 않습니다.

## 접근성 · 설정
그래픽(품질 · 해상도 · 밝기 · 시야각 · 효과) / 오디오 / **더빙(켜기 · 끄기, 음성 엔진: 자동 · 내장 · 브라우저)** / 조작(감도 · 반전 · 달리기 방식 · **키 재지정** · 시점) / 자막(크기 · 배경 · 화자 이름 · **효과음 자막**) / 게임(난이도 — 어려움은 한 번 붙잡히면 즉시 사망, 점프 스케어 약하게, 번쩍임 줄이기, **고대비 표시**, **UI 크기**, 도움말 팁, 장소 사진 카드). 퍼즐마다 단계별 힌트(금고 3단계 · 다이얼 · 피아노 · 녹음)가 있고 소리 퍼즐은 글자로도 보여 줍니다.

## 테스트
```
npm test                       # 저장 시스템 단위 테스트 (node --test)
python3 -m http.server 8765 &  # 브라우저 회귀 테스트
PW_CORE=<playwright-core> CHROME=<chromium> npm run test:e2e
```
`tests/e2e.mjs` — 지훈 · 서연 각각 새 게임 → 캠코더 → 금고(**연 직후 저장/복원**) → 5조각(자물쇠 · 다이얼 · 조합 · 낚기) → 조합 → NORMAL, 별도로 명찰 → 퓨즈 · 배선 → 마지막 방송 → 민아 → TRUE, 캐릭터 유지 · 손상 세이브 백업 복구 · 테스트 세이브 분리. 저장/복원 20회.

## 라이선스 주의
- three.js: MIT. 이미지 · 레퍼런스 시트: 프로젝트 소유자 제공.
- **더빙**: 기본값 `자동` 은 감정 · 화자별로 만든 내장 더빙을 쓰고, 내장 파일이 없는 대사만 브라우저의 자연스러운 한국어 음성(예: Edge 의 SunHi · InJoon Online (Natural))으로 읽습니다. 설정 › 더빙에서 끌 수 있습니다(자막은 그대로).
- **내장 음성**: Microsoft Edge 신경망 음성(SunHi · InJoon · Hyunsu)으로 화자 나이 · 성별과 감정에 맞춰 합성했습니다 (`tools/gen_voice_edge.py`). Edge 의 '소리 내어 읽기' 서비스를 쓴 것이므로 **개인 · 비상업 용도만** 가능합니다. 유료 판매 · 상업적 배포 전에는 상업 라이선스 음성이나 성우 녹음으로 교체해야 합니다. 예전 오프라인 생성기(`tools/gen_voice.py`, KSS · CC BY-NC-SA 4.0)도 남아 있습니다.
- **더 자연스러운 음성(무료 · 비상업)**: `pip install edge-tts` 후 `python3 tools/gen_voice_edge.py` — Microsoft Edge 신경망 음성으로 화자(나이 · 성별)와 감정에 맞춰 모든 대사를 다시 만듭니다. Edge 의 '소리 내어 읽기' 서비스를 쓰므로 개인 · 비상업 프로젝트에서만 사용하세요.
