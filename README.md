# 폐교 — 잊혀진 시간

레퍼런스 시트(폐교 배치도·정문·교실·소품)를 바탕으로 만든 1인칭 3D 학교 공포 게임. 브라우저에서 바로 실행됩니다 (Three.js, 외부 에셋 없음 — 텍스처·사운드 모두 코드로 생성).

## 바로 플레이
```
./start.sh        # 또는: npm start / python3 -m http.server 8000
→ 브라우저(Chrome·Edge 권장)에서 http://localhost:8000 접속 → "새 게임" → 주인공 선택
```
**온라인 플레이:** https://sms9356.github.io/testgame/ (테스트 모드: https://sms9356.github.io/testgame/?test)
`main` 에 머지되면 워크플로가 `gh-pages` 브랜치를 갱신하고 GitHub Pages가 자동 배포합니다 (`.nojekyll` 포함). 데스크톱 키보드+마우스 전용, 헤드폰 권장.

## 업데이트: 미니게임 · 3인칭 시점 · 이벤트 · 특수효과 (최신)
**미니게임 6종** (`minigames.js`) — 열쇠 조각과 특별 목표가 퍼즐로 지켜진다 (플레이 시간 약 1시간 기준)
- **자물쇠 따기**: 머리핀 각도를 맞추고 Space로 돌리기, 무리하면 핀이 부러짐 → 도서실 대출 데스크 서랍 · 교실 보관함 2곳(보급품)
- **다이얼 자물쇠**: 과학실 약품장(칠판 메모 — 원주율), 체육관 기구함(전광판 점수)
- **배선 퍼즐**: 지하 차단기 — 예비 퓨즈(발전실)를 끼운 뒤 타일을 돌려 회로 연결
- **피아노**: 악보(음악실)의 선율을 연주 → 숨은 칸에서 사진 · 건전지 · 머리핀
- **찢어진 사진 맞추기**: 미술실 3×3 슬라이딩 퍼즐 → 사진 · 응급 밴드
- **갈고리 낚기**: 대걸레 자루(지하 청소도구실) + 철사(별관 기술·가정실)를 소지품에서 **조합** → 수영장 배수구 아래 열쇠 조각을 타이밍에 맞춰 건져 올림
- 목표 패널 · 지도에 각 열쇠 조각의 잠금 방식과 필요한 도구가 표시되고, 4분 동안 진전이 없으면 힌트

**시점** — `V` 로 1인칭 ↔ 3인칭(어깨 너머) 전환. 지훈 · 서연 3D 모델(걷기 · 손전등 든 팔), 벽에 부딪히면 카메라가 당겨짐, 손전등 빛이 손에서 나감. 설정에서 기본 시점 · 카메라 거리 지정

**새 생존 요소**
- 빈 캔 8개: `G` 로 던지면 떨어진 곳에서 소리가 나 그것을 유인
- 사물함 안에서 `Space` 를 누르고 있으면 숨 참기 (게이지, 다 쓰면 헐떡임)
- 손전등을 그것에게 똑바로 비추면 느려지고, 버티면 물러난다 (배터리 크게 소모, 재사용 대기)

**새 이벤트**: 천장 타일 낙하(먼지), 컴퓨터실 모니터가 일제히 켜지는 노이즈 화면, 앞으로 이어지는 젖은 발자국, 울리는 교무실 전화(받으면…), 화장실 거울의 글씨, 번개 칠 때 창밖에 서 있는 그림자, 안에서 두드리는 사물함

**특수효과**: 범용 입자(먼지 폭발 · 그것 주변의 검은 연기 · 추운 곳의 입김), 야외에서 렌즈에 맺히는 빗방울, 번개가 실내 창으로 들어오는 섬광, 효과음 14종 추가(핀 · 텀블러 · 다이얼 · 피아노 음 · 캔 · 갈고리 · 퓨즈 · 무너짐 등)

**버그 수정 · 점검**: 소지품 · 지도 · 미니게임 중에는 3D를 다시 그리지 않아 느린 기기에서도 퍼즐이 끊기지 않음, 미니게임 뒤 시점 조작이 풀렸을 때 "클릭하여 계속" 안내, 이벤트 리스너 누수 수정. 아이템 77개 · 장치 21개 · 사물함 26개 도달 가능 검사, 랜덤 입력 장시간 테스트(오류 0)

## 업데이트: 스토리 · UI 체계화 · 설정 · 소지품 · 극사실 텍스처
**이야기** — 10년 전 10월 12일, 서문고 3학년 2반 윤하늘은 방송부의 '담력 체험' 장난으로 지하 펌프실에 갇혔고, 그때 정전이 났다. 학교는 사고를 '실종'으로 덮고 정문 열쇠를 다섯 조각으로 나눠 숨겼다. 매년 그날 밤 꺼진 스피커가 울린다. 올해, 서현고 방송부장 **민아**가 괴담 영상을 찍으러 들어갔다가 연락이 끊겼다.
- **5개 장(챕터)**: 닫힌 정문 → 교무실의 금고 → 다섯 조각 → 마지막 조각 → 다시, 여기서. 장이 바뀔 때 타이틀 카드, 목표 패널에 장 · 메인 목표 · 위치(📍) · 세부 목표
- 새 단서: 1-1 교실의 **민아의 캠코더**(녹화 재생), 지하 펌프실의 **윤하늘의 명찰**, 방송실 장비실의 **민아**
- **특별 목표 · 하교 방송** (진 엔딩 조건): 명찰 찾기 → 지하 전기실 차단기 → 방송실에서 하늘의 이름을 불러 하교 방송 → 그것이 사라짐 → 장비실의 민아 깨우기
- **엔딩 3종**: TRUE(민아와 함께 탈출) · NORMAL(혼자 탈출) · BAD(쓰러짐). 엔딩 화면에 플레이 시간 · 찾은 기록 · 난이도 · 쓰러진 횟수, 갤러리에서 엔딩 수집 확인
- 쪽지 16장 · 녹음 4개 · 사진 3장이 하나의 진실로 이어지도록 전부 다시 씀 (`story.js` 에 대사 · 내레이션 · 쪽지 · 아이템 · 조합식 · 챕터 데이터를 모음)

**주인공 선택** — 캐릭터 시트 반영: **지훈**(18세, 3학년, 차분함 · 관찰력) / **서연**(17세, 2학년 방송부, 호기심 · 용기)
- 대사 44개 × 2명 모두 다른 문장과 목소리로 더빙, 표정 4종(기본 · 차분/호기심 · 놀람 · 결의)이 상황에 따라 바뀜
- 고유 능력 — 지훈: 체력 +25%, 근처의 조사 가능한 단서가 반짝임 / 서연: 배터리 소모 -25%, 다가오는 그것의 방향을 화면에 표시
- 시작 소지품이 다름 (학생증 · 휴대폰 · 메모 수첩 · 방송실 열쇠 / 하트 목걸이)

**UI 체계화** — 타이틀(이어하기 · 새 게임 · 캐릭터 선택 · 설정 · 갤러리 · 제작진 · 게임 종료, 키보드 조작 가능) → 캐릭터 선택 → 인트로 → 게임
- HUD: 왼쪽 위 목표 패널(장 · 메인 · 세부 · 특별 목표), 오른쪽 위 미니맵(문 열림/닫힘 · 장치 · 목표 별) + 원형 버튼(휴대폰 P · 소지품 Tab · 지도 M, 새 메시지 배지), 왼쪽 아래 초상화 · HP/ST/공포, 가운데 아래 퀵슬롯, 대사창(주인공 이름 · 표정), 상호작용 키캡 프롬프트
- **소지품**: 아이템 / 문서 / 열쇠 아이템 탭, 아이콘 격자 + 큰 이미지 상세, **사용 · 조합 · 자세히** (손전등+건전지 = 충전, 열쇠 조각 ×5 = 정문 열쇠 — 정문 · 서문 · 비상 통로는 조합한 열쇠가 있어야 열림), NEW 표시, 방향키 · Enter · C · Z
- **휴대폰**: 메시지(민아의 음성 메시지 다시 듣기) · 사진첩 · 단서 메모(발견한 단서가 자동 기록)
- **지도**: 휠/Z·X 확대, 드래그 이동, 현재 목표 별 · 문 상태 · 장치 · 사물함 · 열쇠 위치 범례
- 일시정지(현재 장 · 플레이 시간, 저장 · 마지막 저장 불러오기), 사망 시 "마지막 저장에서 다시"

**설정** (탭 5개, 모두 저장됨)
- 그래픽: 창/전체 화면, 품질(자동 · 높음 · 보통 · 낮음), 렌더 해상도 50~100%, 밝기, 시야각, 블룸 · 필름 그레인 · 걸음 흔들림 · 충격 흔들림 · FPS 표시
- 오디오: 전체 · 효과음 · 음성 · 환경음 · 음악 / 조작: 마우스 감도, Y축 반전, 달리기 누르기/전환, 조작 안내 표시, 키 목록
- 자막 · 음성: 더빙 방식, 쪽지 읽어주기, 자막 표시 · 화자 이름 · 크기 · 배경 진하기
- 게임 · 접근성: 난이도(쉬움 · 보통 · 어려움 — 속도 · 피해 · 배터리 · 청각), 점프 스케어 약하게, 번쩍임 · 글리치 줄이기, 공포 화면 효과 끄기

**극사실 텍스처 (텍스처 시트 3장 반영)**
- 벽: 위는 크림 → 옛 청회색 → 맨 시멘트로 여러 겹 벗겨진 페인트 · 물 얼룩 · 곰팡이, 아래는 **청록 유약 타일 징두리**(줄눈 때 · 금 · 빠진 타일 · 깨진 모서리) + 나무 몰딩
- 바닥 타일 테라조 골재, 가구 니스 나무 · 도장 금속 · 녹 · 문 · 벽돌 · 외벽 콘크리트 패널(거푸집 이음새 · 빗물 자국 · 이끼)
- 운동장: 갈라진 마른 흙 · 젖은 진흙 · 잡초 · 타이어 자국 · 발자국, **우레탄 트랙**(레인 선 · 출발선), 불규칙한 웅덩이 12곳, 본관 · 담장 · 서문의 **담쟁이덩굴**
- 정문: 벚나무 · 흩날리는 꽃잎 · "서문고등학교" 현수막 · 세로 현판, 본관 현관 계단 · 캐노피 · 교명

- 유령이 경로 첫 지점으로 되돌아가며 떨리던 AI 버그 수정(경로 다듬기)
- 그래픽 품질 설정(일시정지 메뉴: 자동/높음/보통/낮음). 자동은 프레임이 낮으면 단계적으로 낮춤

**문 열고 닫기 (E)**: 모든 교실·특별실·지하·별관의 미닫이문, 화장실 칸막이 문. 닫힌 문은 유령의 **시야를 막고**, 유령은 문을 **쾅 열고** 들어온다.

**3D 디테일**: 3D 창틀·창턱, 라디에이터, 천장 선풍기, 커튼, 교사용 책상(서랍)·교탁, 칠판 프레임·분필·스피커·시계, 실제 책이 꽂힌 책장(인스턴싱), 변기·소변기·세면대, 그랜드 피아노(곡면 몸체·건반·열린 뚜껑), 복도 배관·비상구등·소화기·쓰레기통·낙서, 떨어진 천장 타일·늘어진 전선·매달린 형광등, 범프 맵(벽·바닥·나무·금속 표면 요철)

**이벤트 · 퍼즐**
- 교무실 **금고**(4자리 비밀번호 — 교무회의록과 달력이 단서) 안에 열쇠 조각
- 지하 전기실 **주 차단기** → 3층 방송실 **방송 장비**로 학교 전체에 방송해 유령을 25초간 방송실로 유인 (재사용 대기 90초)
- 정체불명의 **휴대폰 메시지**, 문이 저절로 닫힘, 혼자 울리는 피아노, 칸막이 문이 쾅, 3-3 교실 칠판의 "뒤를 봐", 복도 끝의 그림자, 2층 정전과 다가오는 발소리, 체육관 공 소리, 수영장 물소리

## 품질 개선
- **시네마틱 인트로**: 검은 화면 독백 → 폐교 정문을 향한 카메라 이동 → 타이틀. 정문이 닫히면 자동으로 뒤를 돌아보는 연출 (클릭/Space로 건너뛰기)
- **3D 모델 재작업**: 파이프 다리·서랍이 있는 학생 책상과 의자, 실제로 오를 수 있게 보이는 ㄷ자 계단(층참·난간·천장 개구부), 미닫이 교실 문, 사물함 텍스처, 나무(울퉁불퉁한 수관·가지)와 풀잎 카드, 유령(찢어진 원피스·긴 머리카락·얼굴 텍스처·관절 팔)
- **그림자**: 손전등이 실시간 그림자를 드리움
- **버그 수정**: 인스턴스 가구 크기가 다른 오브젝트 크기로 오염되던 문제(의자·책상 거대화), 벽 너머 아이템/사물함이 잡히던 문제, 화장실·교실 문이 벽을 뚫던 문제, 문틀과 겹치던 사물함, 건물 안에 박힌 나무·풀, 공중에 뜬 쪽지, 출입을 막던 웅덩이 그림자, 정문 자물쇠가 열린 문에 떠 있던 문제
- 자동 검사: 아이템 54개·사물함 26개 전부 접근 가능, 모든 문/계단 도착 지점이 충돌체 밖

## 추가된 시스템 (UI/캐릭터 시트 반영)
- 주인공 **한서연**(20세, 휴학 중 대학생) — 독백 대사창, HP / ST / 공포도 상태창
- HUD: 메인·서브 목표, 원형 미니맵(층 표시·시계), 퀵슬롯 1~4, 획득/알림 토스트
- 인벤토리(Tab): 아이템 / 문서 / 열쇠 탭, 사용하기. 건전지·응급 밴드는 줍고 1~3번 키로 사용
- 지도(M): 층별(옥상·3F·2F·1F/외부) 지도, 목표 위치·조사 완료·사물함 표시
- 유령에게 붙잡히면 HP −50 (잠시 물러남), 0이 되면 사망. 응급 밴드로 회복
- 저장하기 / 이어하기 (브라우저 localStorage, 열쇠 획득 시 자동 저장)
- 새 공간: **옥상** (3F 계단에서 E) — 물탱크, 안테나, 관리실, 문서·아이템

## 확장된 공간 (체육관·방송실·수영장·지하 시트 반영)
- 열쇠 조각이 **6개**로 늘었습니다 (교무실·도서실·과학실·음악실·**체육관 기록석**·**수영장 감시대**).
- **체육관**(운동장 동쪽 건물): 무대·빨간 커튼, 농구 골대, 관람석, 기록석, 기구함(숨을 곳)
- **수영장**(운동장 서쪽 건물): 물 빠진 풀, 출발대, 감시대, 락커, 펌프실(지하로 연결)
- **방송실**(3F): 믹싱 콘솔, CRT 모니터, '방송 중' 경고등, 첫 입장 시 괴이한 교내 방송
- **지하층 B1**(1F 계단에서 Q): 보일러실·전기실·창고·기록실·발전실·펌프실, 열쇠를 모두 모으면 열리는 **비상 통로**(정문 쪽으로 탈출 지름길)
- 문서 5종 추가, 지도(M)에 B1·체육관·수영장 탭 추가

## 급식실 · 별관 · 서문 반영
- **급식실** 내부 진입 가능(운동장 서쪽 건물 정문): 배식대, 조리실, 식당 홀(긴 테이블·스툴), 식재료 창고, 음수대. 열쇠 조각 1개(총 **7개**)
- 별관(특별교실동) 시설을 본관에 통합: 2F **요리실**, 3F **공예실**
- **서문**(서쪽 담장, 쇠사슬로 잠김) 추가, 방송실에 녹음 부스·크로마키·카메라, 수영장에 샤워 부스 칸막이 추가

## 별관 · 서문 밖 · 기타 (최신)
- **별관(특별교실동)** 3층 별도 건물 (본관 뒤편, 본관 북쪽 통로로 이동): 1F 요리실·기술·가정실·창의융합실·진로상담실 / 2F 컴퓨터실·언어실·스마트교실·동아리실 / 3F 음악실·미술실·공예실·과학실. 쪽지 3종 추가
- 수영장 **남/여 탈의실**을 별도 방으로 분리, 방송실에 **장비실**(별도 방) 추가
- **서문 밖** 도로·횡단보도·주차장(방치된 차량)·통학버스·버스 승강장 추가. 열쇠를 모두 모으면 서문 쇠사슬이 끊어져 **서문으로도 탈출** 가능
- 플레이 시간 조절: 열쇠 조각을 **5개**(교무실·도서실·과학실·체육관·수영장)로 줄이고, 나머지 공간은 탐험 보상(건전지·응급 밴드·문서)으로 채움
