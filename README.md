# 폐교 — 잊혀진 시간

10년 전 그날 밤, 지하 펌프실에 갇힌 채 잊힌 한 학생. 그 괴담을 찍으러 들어갔다 사라진 친구 민아를 찾아 폐교에 들어간 주인공이, 빛과 소리에 민감한 존재를 피해 그날의 기록을 모으고 **잊힌 이름을 마지막 하교 방송으로 돌려보내는** 1인칭/3인칭 3D 공포 어드벤처입니다. 브라우저에서 바로 실행됩니다 (Three.js).

- **온라인 플레이:** https://sms9356.github.io/testgame/ (테스트 모드: https://sms9356.github.io/testgame/?test)
- **PC 전용** — 키보드 + 마우스, Chrome · Edge 권장, 헤드폰 권장. 모바일 조작은 지원하지 않습니다.
- 개발 기록은 [CHANGELOG.md](CHANGELOG.md) 에 있습니다.

## 실행
```
python3 -m http.server 8000     # 또는 npm start
→ http://localhost:8000 → 새 게임 → 주인공 선택
```
ES 모듈을 쓰므로 `file://` 로는 열리지 않습니다. `main` 에 머지되면 워크플로가 `gh-pages` 를 갱신해 자동 배포됩니다.

## Unreal Engine 5 병행 포트
`UnrealPort/HaegyoUE` — 웹 게임은 그대로 두고 UE5 버전을 따로 시작한 폴더 (맵 데이터 · UE 텍스처 변환기 · 에디터 자동화 스크립트 · C++ 골격). 현재 단계와 검증 범위는 `UnrealPort/HaegyoUE/README_KR.md`.

## 저장
- 자동 저장(열쇠 · 장치 · 안전 구역 진입 등) + 수동 저장. 저장 시각 · 위치가 타이틀과 일시정지 화면에 표시됩니다.
- `saveSystem.js`: 스키마 버전, **고유 ID 기반**(아이템 · 장치 · 문 · 이벤트 · 팁), 캐릭터 복원, **백업 슬롯**(손상 시 자동 복구), 이전 버전(v4) 세이브 자동 변환, 진행 상태 보정(필수 아이템 영구 소실 방지).
- 테스트 모드(`?test`)는 별도 저장 키를 써서 실제 세이브를 바꾸지 않습니다.

## 의뢰 (서브 퀘스트)
`story.js` 의 `SIDEQUESTS` — 단계마다 방 이름(층) + 방 안 위치(dx, 문에서 안쪽 d m)를 적으면 `game.js` 가 조사 지점을 만든다. 조건(`need`: power · mina · key4 · hairpin), 퀘스트 아이템(`give`/`take`), 문서(`doc` → `NOTES`), 선택지(`choice`), 연출(`event`), 보답(`reward`). 진행은 `FL.sq` · `FL.qi` 로 저장된다.

## V4 실사 모델 제작 (사용자 제작 지시서)
`assets/schoolwide/v4/<ID>/` — Blender 로 만든 원본(.blend) · GLB · FBX · OBJ · 재임포트 검사 · 렌더 · `QC.md`, 제작 스크립트는 `assets/schoolwide/v4/tools/` (`blender --python models.py`). 게임용은 `assets/models/v4_<ID>/` (glTF) + 공용 텍스처 `assets/models/v4_tex/` (Poly Haven CC0 2K · AO). 적용: **R02-01 학생용 책상 · R02-02 학생용 의자 · R02-03 교탁 → 일반 교실 전부** (`?v4=0` 이면 예전 가구).

## 캐릭터 3D 모델 교체 (GLB)
`assets/characters/guard.glb` · `assets/characters/mina.glb` 를 넣고 새로고침하면 지금의 간단한 절차적 경비원(인트로 · 경비실) · 민아(방송실 장비실) 대신 그 모델이 쓰인다.
- 경비원: 키 약 1.75m, `idle` 애니메이션 · 민아: 키 1.62m 모델을 `SittingAgainstWall` 동작으로 앉힘(크기 그대로, `native`) — 깨우면 `Recovery` → `StandUp`
- 현재 둘 다 적용됨 (`assets/characters/Guard`, `assets/characters/Mina`, 검사 기록 `QualityControl/`)
- 미터 단위 · Y-up · 앞 방향 -Z (Blender glTF 2.0 내보내기). 크기 · 바닥 위치는 자동으로 맞춘다
- 파일이 없으면 지금 모델을 그대로 쓴다 (네트워크 탭의 404 한 줄은 정상)
- 지금 저장소에는 GLB 가 **없다** — 캐릭터 시트(2D 그림)는 3D 모델이 아니므로 별도 모델링이 필요하다. 대사 장면의 초상화(`assets/ui/npc_*.webp`)는 시트에서 잘라 바로 쓴다
