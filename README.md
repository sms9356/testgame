# 폐교 — 다시, 여기서

레퍼런스 시트(폐교 배치도·정문·교실·소품)를 바탕으로 만든 1인칭 3D 학교 공포 게임. 브라우저에서 바로 실행됩니다 (Three.js, 외부 에셋 없음 — 텍스처·사운드 모두 코드로 생성).

## 실행
```
python3 -m http.server 8000   # 또는 아무 정적 서버
# 브라우저에서 http://localhost:8000 접속 후 "입장하기"
```
(ES 모듈을 쓰므로 `file://` 로는 열리지 않습니다.)

## 목표
정문이 등 뒤에서 잠긴다. 학교 곳곳(교무실·도서실·과학실·음악실)에 흩어진 **열쇠 조각 4개**를 모아 정문을 열고 탈출하라. 첫 조각을 줍는 순간 그것이 깨어나 학교를 배회한다.

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 마우스 | 이동 / 시선 |
| Shift | 달리기 (체력 소모, **소리가 나서 들킴**) |
| F | 손전등 (건전지 소모, 건전지 줍기 가능) |
| E | 줍기 · 쪽지 읽기 · 사물함에 숨기/나오기 · 계단 오르기 · 정문 열기 |
| Q | 계단 내려가기 |

## 추가된 시스템 (UI/캐릭터 시트 반영)
- 주인공 **한서연**(20세, 휴학 중 대학생) — 독백 대사창, HP / ST / 공포도 상태창
- HUD: 메인·서브 목표, 원형 미니맵(층 표시·시계), 퀵슬롯 1~4, 획득/알림 토스트
- 인벤토리(Tab): 아이템 / 문서 / 열쇠 탭, 사용하기. 건전지·응급 밴드는 줍고 1~3번 키로 사용
- 지도(M): 층별(옥상·3F·2F·1F/외부) 지도, 목표 위치·조사 완료·사물함 표시
- 유령에게 붙잡히면 HP −50 (잠시 물러남), 0이 되면 사망. 응급 밴드로 회복
- 저장하기 / 이어하기 (브라우저 localStorage, 열쇠 획득 시 자동 저장)
- 새 공간: **옥상** (3F 계단에서 E) — 물탱크, 안테나, 관리실, 문서·아이템

## 확장된 공간 (체육관·방송실·수영장·지하 시트 반영)
- 열쇠 조각이 **6개**로 늘었습니다 (교무실·도서실·과학실·음악실·**체육관 기록석**·**수영장 감시대**).
- **체육관**(운동장 동쪽 건물): 무대·빨간 커튼, 농구 골대, 관람석, 기록석, 기구함(숨을 곳)
- **수영장**(운동장 서쪽 건물): 물 빠진 풀, 출발대, 감시대, 락커, 펌프실(지하로 연결)
- **방송실**(3F): 믹싱 콘솔, CRT 모니터, '방송 중' 경고등, 첫 입장 시 괴이한 교내 방송
- **지하층 B1**(1F 계단에서 Q): 보일러실·전기실·창고·기록실·발전실·펌프실, 열쇠를 모두 모으면 열리는 **비상 통로**(정문 쪽으로 탈출 지름길)
- 문서 5종 추가, 지도(M)에 B1·체육관·수영장 탭 추가

## 급식실 · 별관 · 서문 반영
- **급식실** 내부 진입 가능(운동장 서쪽 건물 정문): 배식대, 조리실, 식당 홀(긴 테이블·스툴), 식재료 창고, 음수대. 열쇠 조각 1개(총 **7개**)
- 별관(특별교실동) 시설을 본관에 통합: 2F **요리실**, 3F **공예실**
- **서문**(서쪽 담장, 쇠사슬로 잠김) 추가, 방송실에 녹음 부스·크로마키·카메라, 수영장에 샤워 부스 칸막이 추가

## 별관 · 서문 밖 · 기타 (최신)
- **별관(특별교실동)** 3층 별도 건물 (본관 뒤편, 본관 북쪽 통로로 이동): 1F 요리실·기술·가정실·창의융합실·진로상담실 / 2F 컴퓨터실·언어실·스마트교실·동아리실 / 3F 음악실·미술실·공예실·과학실. 쪽지 3종 추가
- 수영장 **남/여 탈의실**을 별도 방으로 분리, 방송실에 **장비실**(별도 방) 추가
- **서문 밖** 도로·횡단보도·주차장(방치된 차량)·통학버스·버스 승강장 추가. 열쇠를 모두 모으면 서문 쇠사슬이 끊어져 **서문으로도 탈출** 가능
- 플레이 시간 조절: 열쇠 조각을 **5개**(교무실·도서실·과학실·체육관·수영장)로 줄이고, 나머지 공간은 탐험 보상(건전지·응급 밴드·문서)으로 채움

## 구성 (레퍼런스 반영)
- 3층 본관(1F 보건실·상담실·교무실·1-1~1-3·도서실 / 2F 교실·컴퓨터실·과학실 / 3F 교실·미술실·음악실), 중앙 계단, 각 층 화장실, 복도 사물함
- 폐교 정문(기둥 "폐교" 현판, 녹슨 철문, 출입금지 경고판), 운동장, 체육관·급식실 외관, 담장, 숲
- 유령 AI: 순찰 → 소리/시야 감지 → 추격 → 수색. 사물함에 숨어 따돌릴 수 있지만 숨는 걸 들키면 끝.
