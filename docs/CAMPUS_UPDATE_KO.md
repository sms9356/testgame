# 학교 공간·음향 개선

## 시각 및 안정성

- 기존 Poly Haven CC0 실사 재질을 가구 재질에 연결하고 나무·금속·종이·고무·유리를 구분했다. 추가 외부 이미지나 3D 생성은 사용하지 않았다.
- UV 없는 소품은 삼각형마다 일관된 투영축을 사용한다. UV가 있는 모델의 원래 좌표는 보존하며 AO 채널을 별도로 준비한다.
- 창문 아틀라스와 모델 재질 이미지의 디코딩을 기다린 후 GPU에 올린다. 실패한 이미지는 중립 재질로 대체하고 오류를 기록한다.
- 모델의 실제 크기·회전·배율로 특별실 가구 점유 영역을 계산한다. 기존 모델과 새 소품을 모두 예약하고 중앙 이동 통로를 피한다. 기술실 두 작업대에서 겹친 매트도 제거했다. 의자와 책상처럼 의도한 배치는 유지한다.
- 운동장 축구 구역은 잔디 재질로 바꾸고 트랙과 경기장 선은 유지했다. 잔디는 이음새 없는 절차적 텍스처다.
- 외부 가로등 14개와 벽돌 기둥, 층간 금속 띠, 옥상 마감, 현관 캐노피 마감과 학교 표지를 추가했다. 기존 점광원 4개를 공유한다.
- 모델 로딩 동시 작업은 4개로 제한한다. 완료 후 묻힌 아이템 위치를 다시 점검한다. 배포 전 자동 회귀 검사를 실행한다.

## 음향 및 증언

`assets/sfx/CREDITS.md`에 기록한 CC0 실제 종 샘플을 편집해 학교 종·수업 차임·교내방송 시작음을 추가했다. 게임 로컬 파일로 배포하며 외부 사이트 연결이 필요 없다. 원본 학교 현장 녹음이 아니라 실제 종 샘플을 편집한 효과음이다. 로딩 실패 시 기존 합성음을 사용한다.

이야기 음성은 순서대로 재생하며, 재생 중 주인공의 일반 반응이 녹음·방송을 끊지 못한다. 동일 대사의 연속 요청은 합치고, 녹음 중 유령의 짧은 대사는 건너뛴다. 중단 시 대기열도 취소한다. 주인공 자막의 오래된 비동기 응답이 새 타이머를 바꾸지 못하도록 했다. 방송·라디오 잡음 소스도 음성 종료 시 정리한다.

확장 테이프 6개를 사건 관련 증언으로 다시 쓰고 서로 다른 여섯 음색으로 재녹음했다. 상담교사·경비원·과학교사·방송부원·교장·서연의 시점을 구분하며 기존 퍼즐 단서는 남겼다. 보건교사 기록도 별도 여성 증언자로 재녹음했다. 인물의 정체성을 위해 같은 증언은 다시 들을 때 같은 목소리를 사용한다. 실시간 무작위 변조는 하지 않는다. ElevenLabs 모델·음색·해시·길이는 manifest와 연기 설정에 기록했다.

기술 검증은 자연스러운 연기의 사람 청취 검수를 대신하지 않는다. 새 녹음의 상태는 `listening_required`로 유지한다. 외국어 음성 팩 재제작은 포함하지 않는다.

## 실행 검증 (2026-10-16)

- 자동 테스트: 세이브 8개, NPC 3개, 시각 자산 6개, 음향 자산 2개 통과 (총 19개).
- glTF 이미지/버퍼 참조 152개: 누락 0개.
- Chromium + SwiftShader: 모델 69개 로딩 작업 완료, 실패 0개. 메시 7,115개 좌표 유효, 텍스처 858개 준비 완료. 페이지·프레임·텍스처 경고·자산 로딩 오류 0개. 가로등 14개 확인.
- 음성 브라우저 회귀: 지연 요청 취소, 최신 직접 재생 우선, 취소 후 늦은 자막 차단, 증언 중 일반 대사 억제, 이야기 순차 재생, 대기열 취소 통과. 효과음 3종을 재생해도 대사 소스가 중단되지 않음.
- 주요 진행: 캠코더·명찰·퓨즈 획득, 배선 성공 → 전력 복구, 방송 순서 퍼즐 성공 → 진정, 민아 구출, 좌표·전력·구출·방송 상태 저장/복원 통과. F 손전등과 Tab 소지품 동작 통과.
- 첫 W 이동 검사는 촬영 스크립트의 순간이동과 동시에 실행되어 실패했다. 촬영 종료 후 별도 재검사에서 z=50 → 48.152 이동 확인.

제한: 장면 로딩·자산 검사는 실제 렌더러로 수행했다. 이어진 진행 상태 검사는 소프트웨어 GPU 부하를 피하기 위해 검사 도구에서 렌더 호출을 정지한 상태로 수행했다. 위치 이동에 디버그 텔레포트를, 미니게임 성공 판정에 MG.win()을 사용했으므로 전체 보행·미니게임 조작·전 엔딩 검수는 아니다. 현재 환경의 초기 워밍업은 약 44.7초였으며 실제 GPU 성능 측정값으로 해석하지 않는다. 기술 검증 자료는 docs/runtime/campus-*.json에 있다.
