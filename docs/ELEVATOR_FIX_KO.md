# 승강기 객실·승강장 연결 수정

## 원인과 수정

이전 객실은 학교 바깥 x/z=400에 따로 만들고 문턱에서 플레이어를 이동시켰다. 객실 문 밖에는 임시 홀과 벽이 있어, 도착 층의 실제 계단실을 볼 수 없었다. 승강장 안쪽도 평면 객실 그림이었다.

객실을 본관/별관 각 층 계단실의 실제 승강장 위치에 도킹한다. 기존 계단실 동쪽 여유 공간 안에 객실을 넣어 벽 뒤의 다른 교실이나 계단 코어를 침범하지 않는다. 문턱을 지날 때는 좌표·시선을 바꾸지 않고 탑승 상태만 전환한다. 객실 안의 좌표는 도착 층 승강장을 기준으로 보존한다. 두 문과 충돌 상태도 함께 갱신하며, 지나갈 수 있을 만큼 열린 뒤에만 진입/하차할 수 있다.

천장에는 두 줄의 발광 확산판과 따뜻한 객실 조명을 넣었다. 기존 네 개의 조명 풀에서 객실 조명을 우선 배치해 새 PointLight 생성에 따른 셰이더 변형과 재컴파일을 피한다. 비상 전원에서도 객실 조명은 켜진다. 좁은 객실에서는 3인칭 후방 카메라가 벽 밖으로 나가지 않도록 1인칭 위치를 사용하며, 내린 뒤 선택한 시점으로 돌아간다.

문턱에 있는 승객은 자동 닫힘을 막는다. 층 선택은 안쪽으로 들어온 뒤 받는다. 운행 중 저장을 복원하거나 새 게임을 시작하면 운행 토큰을 폐기해 과거 비동기 이동이 새 장면에 적용되지 않게 한다. 객실에서 저장한 데이터는 해당 층의 안전한 승강장 위치로 복원한다. 본관/별관 전환 시 이전 버튼의 텍스처·재질·지오메트리를 해제한다.

## 음향

- 한국어 안내 12개: 문 열림/닫힘, 상승/하강, B1·1·2·3층 도착, B1·1·2·3층 선택.
- ElevenLabs의 기존 한국어 방송 캐스팅(성인 남성, 표준어, 일정한 공식 발성)으로 생성. 모델·입력·음원 해시는 음성 매니페스트와 제작 설정에 기록했다. 실제 승강기 제조사의 음성 파일을 복제하지 않았다.
- 버튼 확인음과 두 음의 도착 차임은 Web Audio로 직접 합성한다. 다운로드나 외부 음원 서비스가 없어도 게임에 포함된 안내 MP3와 함께 동작한다.
- 스토리 음성과 같은 재생 큐를 사용한다. 도착 후 층 안내 → 문 열림 안내 → 실제 문 열림 순서로 처리한다. 진행 중인 대사를 임의로 잘라내지 않는다.

## 검수

단위 회귀와 실제 Chromium 탑승/하차 검사를 사용한다. 층 이동 버튼은 디버그로 선택하고, 객실 진입/하차는 W 키 입력으로 확인한다. 화면 검사는 실제 장면을 렌더링하며, 논리 이동 검사 중에는 소프트웨어 GPU 부하를 줄이기 위해 렌더 호출을 정지한다. 공개 사이트 수동 플레이나 실 GPU 성능 인증과는 구분한다. 결과는 `docs/runtime/elevator-*.json`에 기록한다.

### 확인 결과

- 단위 회귀 102개 및 `npm test` 통과. 신규 검사는 층 순서·좌표 왕복·운행 취소·문턱 승객·12개 음원 해시를 확인한다.
- 탑승/하차·층 이동·화면·저장 복원 브라우저 검사 19개 통과. 도착 층은 본관 B1·1·2·3층과 별관 1·2·3층이며 상승/하강을 모두 검사했다. 페이지/프레임 오류 0.
- 실제 렌더 화면에서 천장 조명과 열린 문 너머의 지하 계단실을 확인했다. 손전등을 끈 상태로 확인했다.
- 기존 음성 큐 브라우저 회귀(취소·최신 요청 우선·실제 음성 길이·늦은 자막 억제·스토리 보호·학교 음향 샘플) 통과.

재현용 탑승 검사는 `tests/elevator.playwright.mjs`에 있다. `PW_CORE`, `CHROME`, `GAME_URL`, `ARTIFACT_DIR` 환경 변수로 Playwright·Chromium·로컬 서버·결과 디렉터리를 지정할 수 있다.

- 모델 69/69 로딩 후 실제 객실 버튼 조준·E 키 작동 확인. 문을 개방한 조건의 조사 대상 531곳 모두 접근 가능했다. 페이지/프레임 오류 0.
