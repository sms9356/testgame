# 게임 분석 및 개선 우선순위

검토 기준: 2026-10-16, main `6a65156592ee595db79b7e6b7dc5613563ea6133`.
`konan/`은 게임 전체 소스가 아니라 화자별 더빙 대본과 ID 모음이다. 실제 실행은 루트의 `index.html`, `game.js`, `world.js`, `story.js`, `audio.js`, `voice.js`가 담당한다.

## 먼저 개선할 항목

| 우선순위 | 확인한 문제 | 권장 개선 및 완료 기준 |
|---|---|---|
| 높음 | 저장 데이터 검증이 `world.items:null`, `docs:{}`, `player.floor:999`를 허용한다. 손상 본 저장과 정상 백업이 있어도 본 저장을 선택한다. `game.js`의 복원 중 객체 접근/forEach에서 실패할 수 있다. | null/배열/객체 구분, 층 범위와 문서 배열 검증 후 상태 적용. 손상 본 저장을 거부하고 정상 백업을 선택하는 회귀 검사 추가. |
| 높음 | 전체 구역의 초기 모델 로딩과 셰이더 준비가 시작 화면을 지연시킨다. `bake.js`의 warmup은 그룹을 모두 표시하고 컬링을 끈 채 준비한다. | 타이틀 먼저 표시, 시작 지역부터 준비, 구역별 로딩 큐. 실제 PC에서 첫 입력 가능 시간과 p95 프레임 시간을 전후 비교. |
| 높음 | `.github/workflows/pages.yml`은 테스트 없이 main을 gh-pages로 force push한다. | 배포 전 단위 테스트와 짧은 브라우저 스모크를 필수화. 실패 시 배포 중단. |
| 높음 | `tests/e2e.mjs`는 위치를 직접 바꾸고 `MG.win()`을 호출한다. 진행 상태 검증에는 유용하지만 실제 이동/조준/퍼즐 입력은 검증하지 않는다. | 새 게임→문 열기→조사→저장→이어하기를 실제 입력으로 검사. console.error와 `__frameErrs`도 수집. |
| 중간 | 일부 조작 안내는 E/F를 고정 표시하여 키 재지정 설정과 어긋난다. | `SET.keys`에서 행동별 표시를 통일. 상호작용을 R로 바꾸면 프롬프트와 튜토리얼 모두 R을 표시해야 한다. |
| 중간 | 다수의 월드 패치 모듈과 큰 `game.js`/`world.js`가 같은 상태를 수정한다. 장소별 문제를 추적하기 어렵다. | 방/문/설비 데이터를 스키마로 정리하고 로딩·상호작용·진행 상태의 경계를 점진적으로 분리. |
| 중간 | `konan/README.md`의 경비는 60대지만 최신 변경 이력과 실제 계정 캐스팅은 충청도 중년이다. README의 음성 안내도 최신 ElevenLabs 팩과 다르다. | 캐릭터 설정과 실제 캐스팅을 한 문서에 기록. 이번 재녹음은 현재 캐스팅을 유지하고 불일치를 명시했다. |

## 이번 변경에서 처리한 더빙 문제

- `audio.js`는 음성 fetch/decode가 끝난 후 재생한다. 기다리는 동안 정지하거나 새 대사를 요청해도 이전 요청이 나중에 재생될 수 있었다. 요청 번호로 오래된 재생을 무효화했다.
- 정지 시 현재 음성 참조를 지운 뒤 ended 핸들러가 배경음 볼륨을 복원하지 못하던 경로를 고쳤다.
- 취소한 대사의 비동기 완료가 자막을 다시 띄우지 않게 했다. 브라우저 합성과 파일 음성 전환 시 이전 엔진도 정지한다.
- 잔향 연결 코드가 줄 끝 주석에 포함되어 실행되지 않던 부분을 분리했다. 녹음 음성의 잔향 전송은 낮게 유지한다.
- 한국어 221줄에 대해 캐스팅·대사별 연기 지시·생성 모델·실제 재생 길이·파일 해시를 기록하는 재생성 경로를 추가했다. 생성 연기와 런타임 피치/떨림/음량 처리를 중복 적용하지 않는다.

## 검토 범위와 한계

공개 게임 URL은 실행 환경의 네트워크 정책에 의해 CONNECT 403으로 차단되었다. 공개 배포본을 직접 플레이했다고 주장하지 않는다. 최신 main의 로컬 정적 서버에서 확인했다. 모든 엔딩의 실제 보행 완주는 이번 범위에 포함하지 않았다.

구조/자산/오류 경로의 검토와 음성 파일 기술 검증은 자연스러움의 청취 평가를 대신하지 않는다. 새 더빙은 PR에서 비교 청취 후 채택할 초안이며 `generation.review_status`에 `listening_required`를 기록한다. 이름 발음, 사투리의 일관성, 나이에 맞는 연기, 숨소리와 대사의 명료도는 직접 청취해야 한다.
