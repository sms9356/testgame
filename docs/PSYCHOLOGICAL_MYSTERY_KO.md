# 심리적 공포 · 선배 실종 사건

## 이야기와 미션

방송부 선배 민아가 일행과 폐교 담력체험을 갔다가 홀로 사라졌다. 돌아온 일행의 말과 현장 녹화·출석 기록이 어긋나고, 주인공은 선배의 흔적과 오래된 실종 사건을 함께 조사한다. 지훈도 2학년으로 정리해 선배 관계를 일치시켰다. 과거 하늘의 사건과 현재 민아의 실종은 서로 다른 사건이다.

- **메인 미션:** 선배의 녹화 발견 → 교무회의록 날짜 추리 → 다섯 장소의 기록/열쇠 퍼즐 → 봉인된 별관 기록 → 방송의 시간 순서 복원 → 민아 구출과 귀환. 선배를 먼저 찾았을 때는 이미 해결한 수색으로 목표가 돌아가지 않는다. 기존 조기 탈출/미완 조사 엔딩은 유지한다.
- **서브 미션:** 개근 기록, 방송부원 진술, 교사의 편지, 반납할 책 등 기존 부탁과 구역/사진 조사를 분리해 표시한다. 발견 전 부탁은 첫 조사 위치만 안내한다.
- **특별 미션:** 방송부원·경비의 모순된 진술, 사건 증언 테이프 6개, 잊힌 이름의 명찰 12개를 복원한다. 기존 저장 플래그에서 상태를 계산하며 별도 진행 데이터를 중복 저장하지 않는다.

휴대폰에 미션 탭과 메인/서브/특별 빠른 이동을 추가했다. 목표 HUD는 현재 단계에 집중하고, 긴 목록은 스크롤된다. 미션 관련 정보는 환각으로 바꾸지 않는다.

## 공포 연출

공격·추격은 재도입하지 않았다. 비명/급작스러운 불협화음을 낮은 잔향과 지속음으로 바꾸고 전체 화면 기습 이미지, 붉은 맥동/줄무늬, 강한 글리치를 줄였다. 전투 난이도 안내는 배터리 소모 기준의 탐색 난이도로 유지한다.

자동 현상은 하나의 연출 시계에서 관리한다. 빈 교실의 출석 소리, 반복되는 시각, 닫힌 창문과 종이 소리, 수업 없는 종소리, 멈춘 뒤 한 걸음 더 이어지는 발소리, 전원 없는 방송의 잔향을 사용한다. 최근 세 유형을 반복하지 않고 약 65~100초 간격으로 배치한다. 대사·방송·퍼즐·메뉴 중에는 새 현상을 시작하지 않으며 이후에도 여유 시간을 둔다. 장소별 기존 기억/초상화/칠판 연출은 남긴다.

관찰한 이상현상은 메모에 객관적 증거와 구분하여 기록한다. 환각 문구는 전용 `기억의 잔향` 영역에만 표시하며 실제 목표·퍼즐·소지품 텍스트를 덮어쓰지 않는다. 도입부/녹화/탐색 메모 5개는 기존 캐스팅으로 재녹음하고 파일 해시와 자막을 맞췄다. 기술 검사로 사람의 연기 청취 검수를 완료했다고 보지는 않는다.

## 안정화 수정

- 저장 복원 후 과거 방송의 예약 콜백이 새로운 장면에 적용되지 않도록 세션 번호를 확인한다.
- 미니게임 중 저장을 복원하면 이전 퍼즐 결과를 폐기한다. 관계없는 새 모달을 닫거나 진행 보상을 주지 않는다.
- 메시지 재시도를 번호별 한 개로 제한하고, 세션 변경/엔딩 뒤에는 이전 재시도를 취소한다.
- 자막·주인공 대사의 이전 타이머와 음성을 세션 변경 시 정리한다. 숨기 UI도 복원 상태와 맞춘다.
- 선택지의 중복 클릭/키 입력을 한 번만 처리한다. 비밀번호 자동 확인+Enter의 중복 보상과 닫힌 키패드의 늦은 해제도 방지한다.
- 수영장 회상은 실제 음성 길이를 기다리고, 장면 이동/저장 복원 뒤의 이전 선택 결과를 적용하지 않는다. 중단 시 회상 색조도 정리한다.
- 도입부·첫 독백·예약된 첫 메시지도 세션을 확인한다.
- 완료 기록은 미션 종류+문구로 구분한다. 오래되거나 잘못된 선택 기록을 읽어도 목표창이 중단되지 않는다.
- 환각 복구 타이머가 더 최근에 갱신한 텍스트를 덮어쓰지 않는다.
- 인트로를 건너뛴 직후 휴대폰을 열면 장 카드/첫 독백이 휴대폰 위로 끼어들지 않는다.

## 검수 범위

단위 회귀, 음성 브라우저 회귀, 실제 메뉴/휴대폰 입력, 저장·복원, 장면 자산 로딩, 조사 도달성, 엔딩/미니게임 결과를 검사한다. 도달성은 문을 개방한 상태에서 플레이어 반지름 .3m, .2m 격자로 검사하며, 걸을 수 있는 지점에서 `findInteract`가 대상을 고르는지 확인한다. 잠긴 컨테이너 속 열쇠와 비밀 자료실은 해당 장치/진행 검사로 별도 취급한다.

소프트웨어 GPU 환경의 부하를 줄이기 위해 초기 장면 준비 뒤 진행 검사에서는 렌더 호출을 정지한다. 엔딩 경로 이동은 디버그 텔레포트, 미니게임 성공은 MG.win()을 사용한다. 전체 방의 실제 보행/퍼즐 조작 완주나 실제 GPU 성능 인증은 아니다. 확인 결과는 docs/runtime/mystery-*.json에 기록한다.

## 확인 결과

- `npm test` 통과. 각 파일 직접 실행으로 확인한 세부 회귀 97개 모두 통과했다.
- 음성 브라우저 검사: 늦은 로딩 취소, 최신 요청 우선, 실제 파일 길이, 오래된 자막 억제, 대사 큐/환경음 우선순위, 학교 음향 샘플 재생 통과.
- 실제 새 게임 메뉴·도입부·휴대폰·미션 탭·선택지 중복 입력·메모 효과·미션 저장 복원 통과. 모델 로딩 69/69 완료, 페이지/프레임 오류 0.
- 문 개방 조건의 조사 대상 531곳 모두 선택 가능한 접근 지점이 있었다. 참조 자산 152개 중 누락 0.
- 지훈 일반·서연 일반·서연 진엔딩 경로 검사 102개 통과, 저장/복원 23회. 조기 선배 구출 뒤 목표 회귀 방지와 기존 서브 의뢰 2건의 진행/아이템 소모도 확인했다.

- 추가 기능 검사 20개 통과, 저장/복원 1회. 사물함 수색·수집품·방 미니게임·칠판·초자연 현상·조합·심령 카메라·배전반·화장실 설비·비전투 접촉을 검사했다.

로컬 브라우저 결과와 GitHub Pages 배포 작업의 성공을 구분한다. 이 환경은 공개 게임 도메인 접속이 제한되어 있어 배포 사이트 자체의 수동 플레이를 했다고 주장하지 않는다.
