# 벽면 승강기와 전용 승강로

이전 수정은 계단실 안에 실제 객실을 배치했지만, 객실 외부를 감싸는 건축 벽이 없어 독립된 상자처럼 돌출돼 보였다. 본관 B1·1·2·3층과 별관 1·2·3층에 동일한 동쪽 서비스 구역을 확보하고, 바닥부터 층간 슬래브까지 이어지는 벽으로 구획했다. 출입문과 버튼·표시등만 계단실 벽면에 보이며 객실의 옆면·뒷면·지붕은 벽 뒤에 들어간다.

승강로는 기존 건물 및 계단실 범위 안에 있다. 서쪽 계단 코어를 바꾸지 않고 코어와 새 벽 사이에 3.24m의 승강장 폭을 남겼다. 문은 새 벽에서 약 6cm 안쪽에 있고 문틀만 일반적인 마감 두께만큼 앞으로 나온다. 맞닿은 벽에는 문 폭 1.6m, 높이 2.4m의 개구부를 둔다. 객실 자체의 실제 층 연결과 안내 음성은 유지한다.

새 벽에 가려지지 않도록 소화기, 지하 안내판, CCTV, 계단실 조명을 옮겼다. 북쪽 창·계단 표지와 1층 별관 연결 통로의 양쪽 출입문도 새 승강장 폭에 맞췄다. 별관 계단 이동 착지점과 본관의 보조 착지점도 벽 앞의 안전한 위치를 사용한다.

기존 저장 위치가 새 승강로 구역 안에 있으면 해당 층의 승강기 문 앞에 복원하고, 남은 점프/계단 높이를 정리한다. 전체 지도와 미니맵에도 승강로 구획을 표시한다. 벽과 승강기 문은 충돌·시야 차단 정보에도 함께 들어간다.

검수는 실제 장면을 렌더링한 정면/측면 화면, 7개 층 구조 검사, 키보드 탑승·하차, 층 버튼 조준/E 입력, 기존 저장 보정, 문 개방 조건의 조사 도달성, 단위 회귀를 사용한다. 이동 검사 중 렌더링은 정지해 소프트웨어 GPU 부하를 줄인다. 공개 사이트 수동 완주나 실제 GPU 성능 인증은 아니다. 결과는 `docs/runtime/shaft-*.json`에 기록한다.

## 확인 결과

- 단위 회귀 104개와 `npm test` 통과.
- 본관/별관의 승강기 7개 층에서 전용 벽과 객실 수용 치수 확인.
- 본관 1층 → B1, 별관 1층 → 3층에서 W 키로 탑승/하차 확인. 실제 층 버튼 조준과 E 키 작동 확인.
- 과거 승강로 안의 저장 위치가 안전한 승강장으로 복원됨을 확인.
- 모델 69/69 로딩 뒤 문 개방 조건의 조사 대상 531곳 접근 가능. 브라우저 페이지/프레임 오류 0.
- 지하 승강장 정면·측면과 별관 정면의 실제 렌더 화면에서 연속된 벽면 마감을 확인.
