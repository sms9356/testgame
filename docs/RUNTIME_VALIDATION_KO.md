## 진행 경로 검사 방식

기존 `tests/e2e.mjs`의 엔딩 경로를 실행했다. 위치와 아이템/장치 선택을 디버그 API로 보조하고 미니게임은 `MG.win()`으로 성공 처리한다. 따라서 모든 구간을 실제로 걸어가거나 모든 퍼즐을 실제 조작으로 푼 완주 검증은 아니다.

반복 진행 체크포인트는 저장 후 좌표를 변경하고 같은 세션에서 `load()`하여 복원을 검사했다. 실제 새로고침/이어하기 검사는 위 UI 검사로 별도 수행했다. 추가 콘텐츠 전체 및 도달성 감사는 이번 더빙 실행 검사의 범위에 포함하지 않았다.

## 남은 한계와 관측 사항

- 이 Chromium에는 합성 음성이 설치되어 있지 않아 브라우저 음성 엔진 선택이 비활성화되는 것을 확인했다. 브라우저 합성 음성의 실제 발성/성별 선택은 검증하지 않았다. 파일 더빙 실행은 검증했다.
- 음성 신호/길이/재생·정지 검사는 감정 연기와 사투리의 청취 검수를 대신하지 않는다. 생성물의 listening_required 표시는 유지한다.
- Google Fonts 요청은 환경 네트워크 제한으로 실패했다. 별도 실제 입력 검사에서는 이 요청 두 건이 console error로 기록되었다. JavaScript 예외나 게임 프레임 오류와 구분한다.
- 페이지 전환 과정에서 GLTFLoader 텍스처 로드 경고가 관측되었다. 실제 입력 검사 기록에는 로컬 이미지 요청의 ERR_ABORTED도 있다. 이를 모두 파일 누락 또는 새 더빙의 오류로 단정하지 않는다. 원래 전체 e2e의 반복 새로고침 방식은 끝까지 실행하지 않았으며, 위에서 명시한 보조 진행 검사와 별도 실제 새로고침 검사로 범위를 구분했다.
- 소프트웨어 렌더러에서 초기 준비 지연은 계속 관측된다. 실제 입력 검사 중 내부 warmup 구간은 약 68.4초였으며, 동시 검사/2 CPU 환경의 결과로 일반 PC 성능을 나타내지 않는다.
- 공개 사이트 배포본, 모든 구간의 실제 보행, 전체 퍼즐 입력, BAD 엔딩 및 모든 추가 콘텐츠는 이번 결과로 검증되었다고 주장하지 않는다.

검증 과정에서 새 더빙 또는 수정된 음성 취소 경로의 실행 실패는 발견하지 않았다. 이번 후속 커밋은 검증 보고서와 결과 JSON만 추가한다. 게임 동작은 변경하지 않는다.
