# 유령을 이야기 연출로 변경

주 유령의 시야·청각 추적, 순찰·추격 이동, 사물함 수색·붙잡기, 최종 광폭화를 제거했다. 이야기 사건에서만 저작된 층 경로점에 잠시 나타나고 사라진다. 플레이어를 향해 이동하지 않으며 접촉해도 체력이 줄거나 부적이 소모되지 않는다.

구역 유령은 모두 증언자로 등장한다. 계단 유령의 기어오기와 돌진, 손 뻗기·전체 화면 비명 연출을 제거했다. 가까이 가거나 비추면 대사를 남기고 사라진다. 화장실 괴담과 선반 수색 실패의 유령 피해도 제거했다. 마이크 소음은 추격을 유발하지 않는다. 유령에 의한 추가 손전등 배터리 소모도 없다.

이전 저장의 enraged/chase/hunt/path 상태는 불러오기와 매 틱에서 초기화한다. 저장 형식이나 퍼즐·열쇠·전력·방송·민아 구출·엔딩 조건은 유지한다. 환경음, 환영, 증언, 사건 연출과 공포 분위기는 남긴다. 다른 환경/퍼즐 위험까지 모두 제거하는 변경은 아니다.

새 단위 회귀 5개: 예전 추격 상태 정리, 등장 지점 고정과 소멸, 기존 hit 호출의 무해성, 구역 증언의 비공격 연출, 계단 유령의 접근 이동 금지. 기존 검사 포함 총 84개.

## 실행 검수 (2026-10-16)

- 단위 회귀 84개 및 GitHub CI 통과.
- 서연 일반 엔딩 경로 35개 확인 통과: 열쇠 5개·열쇠 머리·정문 조합, 중간 저장 복원, NORMAL 엔딩·마지막 선택 C.
- 진엔딩·이동 검사 37개 확인 통과, 저장/복원 5회: 명찰·전력·방송·민아 구출, 의뢰·TRUE 엔딩·마지막 선택 B.
- 각 경로에서 유령 근접 60초 시뮬레이션, 기존 hit 호출, 추격 상태 저장 후 복원에도 체력/부적 손실과 추격 재개 없음.
- 총 11개 층(0~10)의 대표 위치에서 실제 W 키 이동 확인. 페이지/프레임 오류 없음.
- 공격 함수 삭제 후 디버그 내보내기에 남은 참조가 초기화 검사에서 발견되어 함께 제거했다. 이후 진엔딩 경로 초기화와 실행 통과.

진행 검사는 실제 로컬 브라우저에서 수행했으나 소프트웨어 GPU 부하를 줄이기 위해 초기 장면 준비 후 렌더 호출을 정지했다. 엔딩 경로의 이동에는 디버그 텔레포트, 퍼즐 성공에는 MG.win()을 사용했다. W 이동은 실제 키 입력이지만 모든 방의 보행·퍼즐 입력 완주를 뜻하지 않는다. 자료: docs/runtime/story-ghost-validation.json.
