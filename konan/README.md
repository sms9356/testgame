## 코난보이스에서
1. **새 대본 파일 만들기 → 파일 업로드** 에서 화자 엑셀 하나를 올리고, 그 화자에 맞는 **대표 성우** 를 고릅니다. (한 행 = 한 대사. 순서를 바꾸거나 행을 지우지 마세요)
2. 모든 문장의 **포즈(끊어읽기)를 가장 길게** 둡니다 — 대사 사이 무음으로 파일을 자릅니다.
3. 필요하면 문장별 속도 · 피치 · 볼륨을 조정합니다. (효과음은 넣지 마세요 — 자르기가 어긋납니다)
4. 오른쪽 위 다운로드에서 **MP3** 로 내려받아, 파일 이름을 `narrator.mp3` 처럼 화자 이름으로 바꿔 올려 주세요.

발음사전 추천: `서문고 → 서문고`, `2-1 → 이 다시 일`, `B1 → 비원`, `1998 → 천구백구십팔` 처럼 숫자 · 영문이 섞인 곳.

## 게임에 넣기 (개발자)
```
python3 tools/konan_import.py narrator.mp3 konan/narrator_ids.json --dry   # 자를 위치 확인 (줄 수와 길이)
python3 tools/konan_import.py narrator.mp3 konan/narrator_ids.json         # voice/<대사번호>.mp3 + manifest 갱신
```
대본을 다시 뽑으려면: `node tools/dump_lines.mjs lines.json` → `python3 tools/konan_export.py lines.json`.
생성 음성을 게임에 써도 되는지는 코난보이스 이용 약관(상업 · 비상업 범위)을 확인하세요.
